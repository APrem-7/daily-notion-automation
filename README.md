<h1 align="center">To Do List Automation</h1>
<h3 align="center">This is a Python Script Which Generates a new notion Todo List Page Everyday :)</h3>

## Features

- ✅ Automatically creates a new daily ToDo page in Notion
- 📅 Uses IST timezone for date formatting
- 🔝 **NEW: Places new pages at the top of the list** (instead of the bottom)
- ✨ Includes predefined daily tasks with checkboxes

## How It Works

The script:
1. Creates a new Notion page with the current date as the title
2. Adds a list of predefined ToDo items to the page
3. Automatically reorders the pages to ensure the newest one appears at the top

**Note:** Due to Notion API limitations, the script uses a workaround by archiving and unarchiving pages to achieve the desired order.
